Watch the steps

Windows uses Microsoft Edge. A Mac uses Safari. Chrome notes are under each section.

Windows

Pin the browser tab

  1. Open the dashboard in Edge.
  2. Right-click the tab.
  3. Choose Pin. The tab shrinks to an icon on the left and stays there when you reopen Edge.

In Chrome, right-click the tab and choose Pin.

Desktop, taskbar, and Start

  1. In Edge, choose Settings and more (…), then More tools, then Apps, then Install this site as an app.
  2. Name it Emme and choose Install. It opens in its own window.
  3. In the address bar, go to edge://apps.
  4. On the Emme card, choose Details.
  5. Choose Create Desktop shortcut, Pin to taskbar, or Pin to Start. You can use all three.

Start only, without an app window: Settings and more (…) > More tools > Pin to Start. In Chrome, use the three-dot menu, then Cast, save, and share, then Install page as app. Search for Emme in the Start menu, right-click it, and pin it to Start or the taskbar.

Mac

Pin the Safari tab

  1. Open the dashboard in Safari.
  2. Control-click the tab.
  3. Choose Pin Tab. You can also drag the tab to the left side of the tab bar until it shrinks to the site icon.

A Mac does not have a Start menu. The Dock is the matching place.

Dock and desktop

  1. In Safari, open the dashboard.
  2. From the menu bar, choose File, then Add to Dock. The Share button in the toolbar has the same command.
  3. Name it Emme and click Add.
  4. The icon lands in the Dock. Spotlight and Launchpad can open it too.
  5. For a desktop icon, open Finder, choose Go, then Home, then Applications, and drag Emme onto the desktop.

This needs macOS Sonoma or newer. In Chrome, use the three-dot menu, then Cast, save, and share, then Install page as app. After it opens, Control-click its Dock icon, choose Options, then Keep in Dock.
